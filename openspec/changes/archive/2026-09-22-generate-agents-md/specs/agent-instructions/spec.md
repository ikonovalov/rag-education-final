# Agent Instructions Specification Delta

## Purpose
Вводит требование о наличии в репозитории `master` файла `AGENTS.md`,
являющегося источником инструкций для AI-агентов, и фиксирует обязательное
содержание этого файла. До этого изменения capability не существовала
(`openspec/specs/` в репозитории отсутствовал).

## Requirements

### ADDED Requirements

#### Requirement: Наличие AGENTS.md в корне репозитория
Репозиторий `master` ДОЛЖЕН содержать файл `AGENTS.md` в корневой директории,
содержащий инструкции для AI-агентов, работающих с кодовой базой.

##### Scenario: Агент ищет инструкции в корне репозитория
- **WHEN** AI-агент открывает корень репозитория `master` перед началом работы
- **THEN** файл `AGENTS.md` присутствует в корне и доступен для чтения

#### Requirement: Описание назначения и архитектуры проекта
`AGENTS.md` ДОЛЖЕН содержать краткое описание назначения проекта (кулинарная
RAG-система: гибридный поиск BM25+FAISS, LangGraph, GigaChat) и ключевых
компонентов обработки запроса.

##### Scenario: Агент знакомится с назначением проекта
- **WHEN** агент читает `AGENTS.md` впервые
- **THEN** документ описывает, что репозиторий — RAG-система для рецептов с
  гибридным поиском (BM25 + FAISS) и генерацией ответа через GigaChat

#### Requirement: Актуальная структура репозитория
`AGENTS.md` ДОЛЖЕН описывать фактическую структуру репозитория (точки входа,
модули `src/`, `scripts/`), основанную на реальном состоянии файлов, а не на
устаревшем `structure.txt`.

##### Scenario: Агент ищет карту модулей проекта
- **WHEN** агент читает раздел о структуре репозитория в `AGENTS.md`
- **THEN** перечислены реально существующие файлы и директории
  (`main_agent.py`, `main_workflow.py`, `src/agent.py`, `src/workflow.py`,
  `src/bm25_store.py`, `src/bm25_native_store.py`, `src/generator.py`,
  `src/prompts.py`, `src/rag.py`, `src/reference.py`, `src/utils.py`,
  `src/vector_store.py`, `src/workflow_metrics.py`, `scripts/download.py`,
  `scripts/build_index.py`, `scripts/preprocess_data.py`)
- **AND** документ явно указывает, что `structure.txt` устарел и не является
  надёжным источником истины о структуре проекта

#### Requirement: Инструкции по установке и запуску
`AGENTS.md` ДОЛЖЕН содержать шаги установки зависимостей, построения индексов
и запуска точек входа проекта.

##### Scenario: Агент настраивает окружение для работы с проектом
- **WHEN** агент читает раздел установки/запуска в `AGENTS.md`
- **THEN** документ описывает установку зависимостей через
  `pip install -r requirements.txt`, построение индексов через
  `cd scripts && python download.py && python build_index.py`, и запуск
  Streamlit-приложений (`streamlit run main_agent.py`,
  `streamlit run main_workflow.py`)

#### Requirement: Переменные окружения
`AGENTS.md` ДОЛЖЕН перечислять переменные окружения, необходимые для работы
проекта, на основе `.env-example`, без реальных значений секретов.

##### Scenario: Агент настраивает переменные окружения
- **WHEN** агент читает раздел о переменных окружения в `AGENTS.md`
- **THEN** перечислены имена переменных `GIGACHAT_API_KEY`,
  `GIGACHAT_API_SCOPE`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`,
  `USER_AGENT`
- **AND** документ не содержит реальных значений ключей или токенов

#### Requirement: Известные несоответствия и риски для агентов
`AGENTS.md` ДОЛЖЕН явно предупреждать агентов об известных несоответствиях
между документацией/кодом и фактическим состоянием репозитория, не предлагая
их исправление в рамках чтения документа.

##### Scenario: Агент сталкивается с нерабочим импортом в main_workflow.py
- **WHEN** агент читает раздел известных несоответствий в `AGENTS.md`
- **THEN** документ предупреждает, что `main_workflow.py` импортирует
  `from src.rag_pipeline import (graph, graph_callbacks)`, а модуль
  `src/rag_pipeline.py` в репозитории отсутствует (фактический аналог —
  `src/workflow.py`)

##### Scenario: Агент сталкивается с пустым config.yaml
- **WHEN** агент читает раздел известных несоответствий в `AGENTS.md`
- **THEN** документ предупреждает, что `config/config.yaml` пустой (0 байт) и
  фактически не используется для конфигурации, несмотря на упоминания в
  README/structure.txt

#### Requirement: Указание на отсутствие тестов, CI и линтеров
`AGENTS.md` ДОЛЖЕН явно фиксировать отсутствие тестовой директории, CI-пайплайнов
и конфигураций линтеров/форматтеров на момент написания документа, чтобы
агенты не тратили время на поиск несуществующих команд проверки.

##### Scenario: Агент ищет команду для запуска тестов
- **WHEN** агент читает раздел о проверках качества в `AGENTS.md`
- **THEN** документ явно указывает, что директория `tests/`, CI-конфигурация и
  конфиги линтеров/форматтеров (`pyproject.toml`, `setup.cfg` и т. п.) в
  репозитории отсутствуют на момент написания документа
