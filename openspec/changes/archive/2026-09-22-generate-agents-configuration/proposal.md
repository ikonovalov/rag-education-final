# Proposal: generate-agents-configuration

## Why

AGENTS.md — необходимый документ архитектуры проекта, который определяет роли, ответственность и взаимодействие AI-агентов в системе HGSDLC Runtime. 

Текущее состояние:
- Документ отсутствует
- Разработчики и AI-системы не имеют единого источника информации о структуре агентов
- Нарушена информационная согласованность (CLAUDE.md ссылается на несуществующий AGENTS.md)
- Затруднено расширение архитектуры новыми агентами

Проект уже содержит две полноценные линии агентов:
- **ChiefAgent** — интерактивный ReAct-агент для общения с RAG-системой
- **RagWorkflow** — программируемый граф для батч-обработки и оценки

Эти компоненты нуждаются в архитектурной документации для связи с HGSDLC Runtime.

## What Changes

Создаётся комплексный документ AGENTS.md в `rag-education/`, который:
- Описывает архитектуру многоагентной системы проекта
- Определяет роли, типы и интерфейсы агентов
- Документирует инструменты и компоненты (RAG pipeline, LLM, retrievers)
- Показывает взаимодействие между компонентами (диаграммы)
- Предоставляет инструкции по запуску и конфигурации каждого агента
- Закрепляет соглашения (язык, кодирование, логирование)
- Определяет сценарии использования (интерактивный чат, батч-обработка, оценка)
- Связывает архитектуру с HGSDLC Runtime процессом

## Capabilities

Изменение охватывает пять ключевых возможностей системы:

- `agent-interface`: Определение универсального интерфейса для всех агентов в системе
- `chief-agent`: Спецификация интерактивного ReAct-агента для работы с кулинарной RAG-системой
- `rag-workflow`: Спецификация граф-ориентированного рабочего процесса для батч-обработки
- `rag-pipeline`: Спецификация компонентов RAG (retrievers, reranker, LLM interface)
- `hgsdlc-integration`: Спецификация интеграции агентов с многошаговым HGSDLC Runtime процессом

## Impact

**Затронутые компоненты:**
- `rag-education/` — полная архитектура проекта
- `rag-education/AGENTS.md` — новый документ (будет создан)
- Все существующие агенты: ChiefAgent, RagWorkflow, Generator
- Связь с HGSDLC Runtime (узлы ai-describe-change, ai-explore и т.д.)

**Зависимости:**
- Изменение не имеет внешних зависимостей на внутреннюю реализацию
- Все компоненты (ChiefAgent, RagWorkflow) уже существуют и работают
- AGENTS.md — документ, описывающий текущее состояние архитектуры

**Риски:**
- Низкие. Это документирование существующей архитектуры, без изменений кода.
- Единственный риск: неполнота или неточность описания (минимизируется через specs и review)

## Success Criteria

1. ✓ AGENTS.md создан и размещён в `rag-education/AGENTS.md`
2. ✓ Документ содержит описание всех пяти capabilities (agent-interface, chief-agent, rag-workflow, rag-pipeline, hgsdlc-integration)
3. ✓ Для каждой capability существует delta-spec с требованиями и сценариями
4. ✓ Документ включает диаграммы архитектуры (текстовые или ASCII)
5. ✓ Инструкции по запуску и конфигурации проверяются хотя бы одной тестовой командой
6. ✓ Соглашения проекта (язык, логирование, кодирование) задокументированы
7. ✓ Сценарии использования (интерактивный чат, батч-обработка, оценка) описаны с примерами
8. ✓ Документ согласуется со всеми ссылками в CLAUDE.md и может служить архитектурным ориентиром
