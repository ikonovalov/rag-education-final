# Proposal: Создание AGENTS.md для репозитория master

## Why
Репозиторий `master` (кулинарная RAG-система: гибридный поиск BM25+FAISS,
LangGraph, GigaChat) не содержит ни одного файла с инструкциями для AI-агентов
(`AGENTS.md`, `CLAUDE.md`, `QWEN.md`, `GIGACODE.md` отсутствуют). Из-за этого
любой AI-агент, приступающий к работе с репозиторием, вынужден заново
реконструировать структуру проекта, порядок установки и запуска, а также
рискует опираться на устаревший `structure.txt` (описывает шаблонную
структуру `rag_pipeline.py`, `retriever.py`, `tests/`, которая не совпадает с
фактическим составом репозитория) или не заметить нерабочий импорт
`from src.rag_pipeline import ...` в `main_workflow.py`.

Пользователь явно запросил создание `AGENTS.md`.

## What Changes
- Добавляется новый файл `master/AGENTS.md` — единственный источник инструкций
  для AI-агентов в репозитории (других подобных файлов нет, конфликтов
  приоритета не возникает).
- Файл фиксирует: краткое описание проекта, актуальную структуру репозитория,
  порядок установки/запуска, переменные окружения (по `.env-example`, без
  реальных секретов), известные несоответствия и риски (устаревший
  `structure.txt`, нерабочий `main_workflow.py`, пустой `config/config.yaml`),
  а также явное указание на отсутствие тестов, CI и линтер-конфигов.
- Код и поведение системы не меняются — изменение чисто документационное.
- Вне скоупа: исправление нерабочего импорта в `main_workflow.py`,
  актуализация `structure.txt`, заполнение `config/config.yaml` — эти факты
  только фиксируются как предупреждения для агентов.

## Capabilities
- `agent-instructions`: требование о наличии и содержании `AGENTS.md` в
  корне репозитория `master` как источника инструкций для AI-агентов,
  работающих с этим кодом.

## Impact
- Затрагивает только новый файл `master/AGENTS.md`; исходный код, тесты,
  конфигурация и зависимости не меняются.
- Влияет на будущих AI-агентов (и людей-контрибьюторов), которые будут
  ориентироваться на `AGENTS.md` при работе с репозиторием.
- Риск: если содержание `AGENTS.md` разойдётся с кодом в будущем (например,
  после реструктуризации `src/`), файл придётся обновлять отдельным
  изменением — сам этот процесс вне скоупа текущего изменения.

## Success Criteria
- Файл `master/AGENTS.md` создан в корне репозитория `master`.
- Файл описывает: обзор проекта, актуальную структуру репозитория, шаги
  установки и запуска, переменные окружения из `.env-example`, известные
  несоответствия/риски (structure.txt, main_workflow.py, config.yaml),
  отсутствие тестов/CI/линтеров.
- Файл не содержит реальных значений секретов (ключи API, токены).
- Существующий код репозитория (main_agent.py, main_workflow.py, src/*,
  scripts/*) остаётся без изменений.
